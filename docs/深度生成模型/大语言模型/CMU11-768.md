# CMU 11-768: AI Agents

## 课程简介

- 所属大学：Carnegie Mellon University
- 先修要求：具备训练神经语言模型的经验，建议具有 CMU 11-667、11-711、10-202 或同等课程背景。
- 编程语言：Python
- 课程难度：🌟🌟🌟🌟
- 预计学时：100 小时

本课程由 Graham Neubig 和 Daniel Fried 授课，围绕基于大语言模型的智能体展开，介绍如何让模型通过工具调用、上下文管理、记忆和规划完成多步骤任务。课程内容涉及代码智能体、计算机操作智能体、监督微调、强化学习、智能体框架、安全性，以及人与智能体、多智能体之间的交互。

课程强调动手实现，安排了智能体运行框架、评测和训练三个主题的个人作业，以及后半学期的研究项目。适合已有语言模型训练经验，希望进一步学习智能体构建、评测与训练的学习者。上述难度与学时为自学估计，100 小时包含观看课程、阅读材料和完成三个作业，不包含完整研究项目。

截至 2026 年 10 月，2026 秋季课程仍在进行中，录像、讲义和作业资源持续更新。课程网站已经提供部分录像和公开作业材料，但作业提交通过仅面向 CMU 学生的 Canvas 进行。部分实践需要模型 API 和云计算服务，自学者应自行确认资源与费用。
